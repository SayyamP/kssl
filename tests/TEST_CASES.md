## 1. What the system actually is

### 1.1 Frontend — `frontend/`

Single-page React 18 app (vite 5), no router library: the URL **hash** is the only route
(`src/lib/route.js`). Dev on `:5178`, preview on `:5179`, production a static bundle in a
Caddy container.

| Pillar | Views (rail) | Archived but still routed |
|---|---|---|
| `competitive` | `overview`, `profile`, `products`, `positioning`, `partnerships`, `geo`, `patents-comp` | `gap-competitive` |
| `market` | `m-overview`, `m-report`, `tender` | `awarded-tenders`, `closed-tenders` |
| `technology` | `t-overview`, `innovation` | — |

Route form: `#p=<pillar>&v=<view>`. `parseRoute` repairs an unknown **view** to that
pillar's overview and returns `null` for an unknown **pillar**.

Components exercised: `TopBar` (pillar pills, global search), `SubHead` (heading, count
line, Copy Summary / Export JSON / Print Report), `MetricsStrip` (tiles, some of which
are doors to other views), `Sidebar` (rail + corpus-derived counts), `Overview` (feed,
direction filters, feed search, pagination), `SignalCard`, `DetailPanel`, `GeoMap`
(leaflet), `MalloryChat` / `AskBox` / `ScopeChat` (**offline** answer engines — no model
call), `ErrorBoundary` (one per view, keyed).

A second, separate page: **`/ops/`** — `frontend/public/ops/index.html`, the read-only
operator console. Six tabs: System Overview, Pipeline Explorer, Document Lineage, Live
Event Stream, Run Timeline, Signal Explorer. Plain ES, no build step.

### 1.3 Authentication & authorization — the honest picture

- **The only authentication is HTTP Basic**, enforced by **traefik**, not by the
  application: middleware `kssl-auth`, user `kssl`, hash in `KSSL_BASIC_AUTH`
  (`docker-compose.vps.yml:146-157`, generated by `deploy/provision_env.sh`).
- It guards **both** routers: `kssl-web` (the UI **and** `/ops/`) and `kssl-api` (`/api`).
- `backend/app.py` contains **no authentication code at all** — no session, no cookie, no
  JWT, no API key.
- **There are no roles.** No user table, no permission check, no admin/viewer split
  anywhere in the frontend or the backend. Access is all-or-nothing.
- Security headers come from middleware `kssl-sec` — applied to `kssl-web` **only**, not
  to `kssl-api`.
- CORS in FastAPI is `allow_origins=["*"]`.

Tests therefore assert the real boundary (SEC-001..SEC-007) and do **not** fabricate a
role matrix.

### 1.7 Business workflows

1. **Corpus → queue**: `select_worklist.py` (P1..P7 lanes) and `route.py --enqueue`
   (freshness/presignal classes) fill `extract_queue`; `--reap` returns expired leases;
   `--backfill` tops `ready` back up from gate-refused rows.
2. **Queue → extracted**: `run_node.py` claims with `FOR UPDATE SKIP LOCKED`, calls the
   farm, and writes spans **plus** the done-mark in one transaction, fenced on
   `lease_epoch`.
3. **Extracted → serving**: `serving_fill.py` writes cards/details (re-gating and
   re-translating each pass); `enrich_serving.py` rebuilds the other serving tables,
   then `fill_competitor_news.py`, `mark_shared.py`, `backfill_tie_status.py` repair what
   the rebuild cascaded away.
4. **Serving → dashboard**: `GET /api/dataset` in one round trip → `DataProvider` →
   every panel.
5. **Provenance**: `provenance.event` + `metrics.stage_run` → the operator console.

rule — one definition, not two.
